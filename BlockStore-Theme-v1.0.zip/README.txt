----------------------------------------
  HOW TO USE
----------------------------------------

1. Extract the ZIP file
2. Open index.html in any browser
3. To customize:
   - Edit text in index.html (or use admin panel)
   - Edit colors in css/style.css (top of file, :root section)
   - Edit translations in js/main.js

----------------------------------------
  ADMIN PANEL (DEMO)
----------------------------------------

1. Open admin.html
2. Password: admin123
3. Edit ranks, prices, perks
4. Click "Save Changes"
5. Open index.html to see the changes
6. Use "Reset to Default" to undo

IMPORTANT: This is a DEMO admin panel. Data is stored in
the browser's localStorage only. For a real store, you
need a backend + database (PHP, Node.js, etc.).

----------------------------------------
  CUSTOMIZATION TIPS
----------------------------------------

Colors:
  Open css/style.css and edit the :root section:
  --accent: #4ade80;     → main green color
  --gold: #fbbf24;       → gold color
  --purple: #a78bfa;     → purple color

Fonts:
  Open index.html and change the Google Fonts link.
  Default: Press Start 2P (pixel) + Inter (body)

Translations:
  Open js/main.js and edit the "translations" object.

Logo:
  Open index.html and change "BlockStore" text + logo.
